# 🚀 IT Business Analysis Portfolio

Xin chào! Mình là **Đinh Thị Hải**, sinh viên chuyên ngành **Hệ thống Thông tin (IS)**. 

Đây là không gian lưu trữ các dự án thực tế và đồ án học thuật của mình trong vai trò **IT Business Analyst (BA)** và **Project Manager (PM)**. Các tài liệu tại đây phản ánh tư duy hệ thống, khả năng khơi gợi yêu cầu, chuẩn hóa quy trình và thiết kế giải pháp phần mềm của mình.

---

## 🛠️ Kỹ năng cốt lõi (Core Competencies)
* **Nghiệp vụ BA:** Requirement Elicitation, To-be Process Modeling, viết BRD, SRS, User Stories & Acceptance Criteria.
* **Hệ thống & Dữ liệu:** Sơ đồ UML, DFD/ERD, thiết kế cơ sở dữ liệu (SQL, SQLite, MongoDB), hiểu về API và vòng đời SDLC.
* **Công cụ:** Figma (Wireframing), Draw.io.
